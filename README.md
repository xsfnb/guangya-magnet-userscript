# 光鸭云盘 · 磁力离线下载（油猴脚本）

在任意网页上识别磁力链接，旁边直接显示「☁ 离线下载」按钮，一键把资源添加到光鸭云盘的离线下载（云添加），并按剧名自动建文件夹归类。

> 非官方项目，与光鸭云盘官方无关。使用的是网页端接口，随时可能因官方调整而失效。

## 功能

- **页面磁力识别**：`<a href="magnet:...">`、`data-clipboard-text` 等 data 属性、输入框里的磁力、`title` / `aria-label`、纯文本磁力都能识别
- **行内按钮**：识别到的磁力旁直接出现「☁ 离线下载」，无需悬停；动态加载 / 翻页 / 懒加载的内容会自动补按钮
- **添加前预览**：显示总大小、文件数、创建时间；可勾选具体文件（默认勾选 ≥10MB 的视频），目录可展开
- **保存目录**：支持目录树选择，记住上次选择的目录，默认自动定位「来自：云添加」
- **同剧归类**：添加时自动按剧名建子文件夹（如 `學生會也有洞！`），一个剧的所有集数落到同一个文件夹
- **整目录归类**：对已经散落在某个文件夹里的多集资源，菜单一键分组 → 建目录 → 移动
- **本页批量添加**：一个列表页里有多条磁力时，一次全部提交
- **Token 自动获取与刷新**：登录光鸭网页端后自动嗅探 Authorization，过期自动用 refresh token 续期
- **调试日志**：出问题时可在控制台看到每次请求与响应

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）或 ScriptCat
2. 打开管理面板 → 新建脚本 → 清空模板 → 粘贴 `guangya-magnet-cloud-add.user.js` 全文 → `Ctrl+S` 保存
3. 首次使用：打开 <https://www.guangyapan.com/> 登录一次（脚本会自动嗅探 Token）

## 使用

### 单条磁力

磁力链接旁边点「☁ 离线下载」→ 预览文件 → 选择「添加到」目录 → 立即添加。

### 自动归类

默认开启。添加时会按文件名推断剧名并自动建子文件夹：

```
[ANI] 學生會也有洞！ - 04 [1080P][Baha][WEB-DL][AAC AVC][CHT].mp4
        ↓
學生會也有洞！/  ← 自动建的同名文件夹
```

弹窗里会用绿色标出目标文件夹；建目录失败会自动回退到所选目录并在状态栏提示。

### 整理已有文件

进入要整理的文件夹 → 油猴菜单 →「🗂 同剧归类（当前文件夹）」。

规则：同一部剧至少 2 个文件才归类；只处理当前目录（不递归）；文件夹会被跳过。

### 菜单项

| 菜单 | 作用 |
|---|---|
| 📚 批量添加本页全部磁力 | 把当前页所有识别到的磁力依次提交 |
| 🗂 同剧归类（当前文件夹） | 整理当前目录里散落的多集资源 |
| 🎯 切换：添加时自动按剧名建目录 | 开关自动归类 |
| 🔘 切换：页面内「离线下载」按钮 | 嫌按钮碍眼时可以隐藏 |
| 🐞 切换：调试日志 | 打印请求/响应到 F12 控制台 |
| ☁ 设置 Authorization Token | 手动填写凭证 |
| 🔑 设置 Refresh Token | 手动填写 refresh token |
| 🧹 清除自动 Token 和 Refresh Token | 凭证异常时重置 |
| 🔄 重置保存目录 | 忘记上次选的目录时使用 |

## 常见问题

**提示「未获取到登录凭证」**
先打开并登录 guangyapan.com；仍不行就在菜单里手动填 Token。

**添加成功但任务状态是「参数错误」**
`create_task` 只接受 `{ fileIndexes, url, parentId }`，多传字段或文件序号对不上都会导致任务失败。本脚本已按网页端实际参数提交，若仍失败请开调试日志，把 `create_task` 的响应发到 Issues。

**没识别出剧名 / 归错类**
剧名是从文件名推断的：会去掉 `[组名]`、`[1080P]` 这类方括号标签，再截断到第一处集数标记（`S01E02`、`EP07`、`第07话`、独立的 `07`）。命名不规范时可能识别失败，此时不会归类，文件留在原目录。

**归类后又出现散文件**
离线下载是异步任务，下载完成的文件才会出现在云盘；归类只作用于已经落盘的文件。
